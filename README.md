# Personal.rec_web

Flask-сайт для поиска аниме через AniList и показа рекомендаций из каталога
Personal.Rec.

## Запуск (Windows / PowerShell)

Открой корень проекта и создай виртуальное окружение:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python app.py
```

Открой `http://127.0.0.1:5000/`. Для поиска похожих тайтлов нужен
`data/raw/anime.csv` из проекта Personal.Rec. Этот небольшой каталог включён
в проект, чтобы рекомендации работали после деплоя. Большой `rating.csv`
оставлен за пределами Git.

Для API рекомендаций по пользовательской истории требуются оба файла
`rating.csv` и `anime.csv`. По умолчанию сайт ищет их в `data/raw/`. Можно
указать каталог другого проекта Personal.Rec через PowerShell:

```powershell
$env:PERSONAL_REC_DATA_DIR = 'C:\path\to\Personal.Rec\data\raw'
python app.py
```

## Возможности и API

- `GET /api/anime?q=<название>` — автодополнение AniList, в том числе для
  русских запросов.
- `GET /api/similar?mal_id=<id>` — подбор похожих тайтлов для выбранного
  произведения. Можно передать `anime_id` AniList, если MAL ID неизвестен.
- `GET /api/recommendations?user_id=<id>&limit=<n>` — персональная выдача по
  профилю пользователя из датасета; `limit` ограничен диапазоном 1–50.
- `/anime/<anilist_id>` — страница с подробностями тайтла.

Поиск похожих аниме сравнивает жанровые TF-IDF-векторы из
`services/recommendation_service.py`. Сиквелы, фильмы и другие тайтлы с общими
характерными словами в названии исключаются из выдачи. Карточки обложек,
названий и оценок загружаются из AniList. Оценка AniList показывается по
шкале 1–10. Процент на карточке — жанровая оценка алгоритма; подпись о
вероятности понравиться является удобной интерпретацией этой оценки, а не
калиброванной статистической вероятностью.

`services/hybrid_recommendation.py` реализует соседскую гибридную модель для
профиля пользователя из CSV. Она фильтрует пользователей менее чем с 50
оценками и тайтлы менее чем с 30 оценками, отбирает соседей по сходству и
использует среднюю оценку пользователя, если коллаборативный прогноз
недоступен. Текущий режим сайта «По моей коллекции» пока ведёт на страницу
регистрации: API можно вызвать напрямую, но он не привязан к коллекции
аккаунта сайта.

Пример вызова из PowerShell:

```powershell
Invoke-RestMethod 'http://127.0.0.1:5000/api/recommendations?user_id=123&limit=10'
```

Замени `123` на ID пользователя, присутствующий в датасете.

## Структура проекта

- `app.py` — Flask-маршруты и сбор карточек;
- `services/anime_search.py` — запросы поиска к AniList;
- `services/anime_catalog.py` — связь AniList ID и MAL ID и загрузка карточек;
- `services/recommendation_service.py` — поиск похожих тайтлов по жанрам;
- `services/hybrid_recommendation.py` — пользовательские гибридные рекомендации;
- `recommendations/similarity.py` — сходство профилей оценок;
- `templates/` и `static/` — HTML-шаблоны, JavaScript и CSS;
- `data/raw/` — локальные CSV-данные, исключённые из Git.

## Примечания

- AniList API вызывается с сервера, поэтому для автодополнения и обложек нужен
  доступ к сети.

## Развёртывание на Render

В корне проекта находится `render.yaml` с настройками Python Web Service,
health check и запуском через Gunicorn. Render Blueprint по умолчанию ищет
этот файл в корне связанного репозитория. Подготовь и отправь в Git изменения
проекта, включая `data/raw/anime.csv`, затем в Render выбери **New → Blueprint**,
подключи репозиторий и подтверди создание сервиса `personal-rec-web`.

Базовый Blueprint настроен на бесплатный тариф. На нём сервис засыпает после
периода без запросов и не имеет постоянного диска; первый запрос после простоя
может ждать запуска. Функции сайта и поиск похожих аниме используют включённый
в репозиторий `anime.csv`, поэтому продолжают работать после перезапуска.

`rating.csv` (около 111 МБ в текущем локальном наборе) намеренно исключён из
Git. Поэтому на бесплатном Blueprint endpoint `/api/recommendations` по
профилю пользователя останется недоступен, пока данные не будут размещены
отдельно. Для него нужен тариф с постоянным диском Render или внешний доступный
каталог данных, где вместе лежат `rating.csv` и `anime.csv`; затем укажи
`PERSONAL_REC_DATA_DIR` на этот каталог. Загрузка рейтингов в Git не
рекомендуется: файл крупный, а free-сервис не сохраняет локальные файлы.

Проверка состояния после деплоя: открой `https://<имя-сервиса>.onrender.com/health`;
ожидаемый ответ — `{"status":"ok"}`.
- Пользовательские ID набора Personal.Rec — это не учётные записи сайта.
- Flask запускается в режиме разработки; для публикации нужен production WSGI
  сервер и отдельная настройка конфигурации.
